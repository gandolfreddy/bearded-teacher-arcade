# v0.5.0 遊戲島

日期：2026-11-03；狀態：實作、本機、遠端與正式站驗收完成。

## 已確認需求與完成條件

使用者要求 2.5D 像素全景島、點按地圖操控獨立角色、右上角小地圖、每次進入先登入／註冊、註冊可選頭髮／性別／表情／衣著。後續明確選擇「只輸入帳號名稱，接受他人可使用該帳號」、「先做自己的角色」、以及「先用瀏覽器 localStorage 就好」。因此本版不使用 Firebase，不建立付費或雲端資源。

1. 地圖：使用 Kenney Tiny Town／Tiny Dungeon 原始 CC0 PNG、原授權與來源留存；Canvas 組裝有建築高度、依 Y 軸遮擋的俯視 2.5D 像素場景。六間小屋對應既有六款遊戲；路徑避開海水、樹與建築；小地圖可點按，另提供方向鍵與遊戲導覽。
2. 帳號：每次完整載入與 bfcache 回復均顯示登入／註冊；路由切換不重登。帳號正規化，不設密碼。以此瀏覽器本機資料為準，無跨裝置同步，清除網站資料會移除角色，不儲存私密資料。
3. 角色：四種頭髮、三種性別選項、三種表情、四種衣著與即時預覽。性別不限制其他選項；角色位置與外觀儲存，重登恢復。
4. 儲存：獨立 IslandStore 模組，註冊成功寫入後才進島；移動停止後合併儲存，切換遊戲／隱藏／離開做同步儲存。容量或權限失敗明示未儲存，可重試；損毀資料不默默覆寫。版本 revision 偵測舊分頁寫入，localStorage 不提供跨分頁交易保證。
5. 驗收：路徑與入口連通、帳號與儲存反例、重新載入登入、角色持久資料、正常走到遊戲／返回、鍵盤／觸控、小地圖、四尺寸與六款回歸；沿用獨立 Playwright 與免費 CI／Pages，部署後查版本。

## 本機驗證與問題修正

50 項規則測試通過（既有 41＋新島嶼／儲存 9）；75 項獨立 Playwright 案例通過（外框 17、貪食蛇／翻牌 14、方塊／跳躍 14、賽車／撞球 16、遊戲島 14）。島嶼涵蓋真實表單登入／註冊、外觀儲存、每次重整重新登入、位置移動／儲存／重登、不可走海水、走到小屋進入／返回、直接遊戲路由登入、防重名、鍵盤與小地圖、儲存權限／容量反例、損毀不覆寫、不同儲存環境隔離、移動儲存失敗重試與跨分頁更新。四種尺寸為 1280×720、1024×768、768×1024、390×844，並旋轉；模擬不等同平板實機。

新增登入後，舊回歸改為預植合成帳號資料、仍透過真正登入表單進入，沒有在產品放登入繞道。一次歷史導覽測試因測試額外導航到清單而多一筆 history，改驗新返回目的地遊戲島並直接上一頁，重驗通過。讀回程式時發現早期新增 hash 白名單的運算子問題，修正後規則測試通過。登入背景從素材圖塊清單改為實際地圖快照；平板地圖標籤維持可讀大小，最終截圖已檢視。最後字級／登入鍵盤變更重驗島嶼 14 項通過。

單代理實作與自我覆核，未委派、未宣稱切換模型；完整代號／強度與精確總耗時未取得。未驗：平板實機、Safari／其他引擎、完整 bfcache 裝置矩陣、長時間效能與休眠、同時多分頁寫入的原子性（localStorage 不提供）。裝置驗收期限與負責人未指定。無新增 Notes 正式 SOP。
