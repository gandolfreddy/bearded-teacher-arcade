# v0.3.0：俄羅斯方塊與小型跳躍關卡

日期：2026-11-03；狀態：本機、遠端 CI／部署及四款正式網站限定操作驗收通過；平板實機待驗。

## 需求與完成條件

- R11：新增 games/tetris.html，提供七種方塊、消行／分數／等級、Hold 與 Next 框。Hold 每顆一次、鎖定後重開；Next 顯示三顆並依序消耗，七袋洗牌；支援旋轉、軟降、硬降及落點預覽。
- R12：新增 games/star-trail.html，提供原創角色與原創畫面的小型橫向跳躍關卡。包含地形、兩個缺口、平台、星星、小怪、踩擊與終點；星星非過關必要條件。鍵盤或觸控可抵達終點，失敗可重玩。
- R13：兩款皆可獨立開啟，也可在大廳以 hash 路由載入。沿用初始化前停用、ready 才顯示、開始／暫停／重玩／返回及卸載；長按與多指輸入需在放開、取消或失焦時正確清除。
- R14：維持公開儲存庫免費標準 Linux CI/CD，不新增服務或依賴。核心／瀏覽器／既有遊戲回歸通過後推送，確認遠端 CI／部署、實際網站版本與新遊戲操作。

## 設計與取捨

原生 Canvas 與獨立規則模組，手寫圖像，無外部角色／音樂素材。俄羅斯方塊採四方向旋轉及有限牆邊位移修正，未宣稱完整官方 Guideline／SRS。Hold 與預覽都有可讀名稱；方塊及角色狀態以 Canvas 的文字標籤提供輔助資訊，不宣稱完整非視覺遊玩支援。

闖關為單一短關卡、固定物理步進與相機橫向跟隨，加入短暫離地跳躍容錯。共用輸入追蹤每個鍵／指標來源，避免同時按鍵或多指互相釋放。GameHost 增加可選 onPause，供新遊戲清空輸入；舊遊戲沿用預設。

## 實作問題與修正

首輪方塊側框占用高度使觸控列部分落到 iframe 視窗下；縮緊預覽尺寸、讓 Hold 圖本身就是保留按鈕，短畫面改成單列觸控鍵，並新增控制項實際範圍的斷言，不以只有無水平溢出取代可用性。

首輪雙指案例放開後移動停止。事件追蹤顯示測試送出的 touchEnd 明確結束了移動指，並非產品把兩指一併釋放。改為結束跳躍指後，證明移動指繼續有效；touchCancel 再停止移動。此差異為測試事件指定修正，沒有放寬輸入規則。

關卡的參考路徑只產生正常右走與跳躍輸入，先以純模型確認可過關，再以真實 Playwright 鍵盤重播相同輸入，不注入玩家位置或跳過碰撞。
