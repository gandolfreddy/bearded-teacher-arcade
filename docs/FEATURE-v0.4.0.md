# v0.4.0：直線賽車避障與迷你撞球

日期：2026-11-03；狀態：本機驗證完成；遠端與正式站待驗。

## 需求與驗收

- R15：games/road-racer.html 三車道直線自動行駛，左右換道／按住減速、逐步加速、障礙預告、碰撞結束、1000 公尺終點及重玩。每波留至少一條通路。
- R16：games/mini-pool.html 單人六球清台練習，六球袋、白球、六顆色球；可鍵盤轉向／調力道／擊球，或觸控球桌瞄準／控制力道。球移動時不可重複擊球；白球落袋記犯規並於停球後安全回位，全色球入袋且停止後完成。
- R17：獨立規則模型驗證賽車生成／碰撞／終點與撞球碰撞／反彈／摩擦／進袋／白球回位。沿用獨立 Playwright、暫停／輸入清除／ready／重玩／獨立入口及四種尺寸；觸控瞄準須換算縮放座標、取消不誤擊球。
- R18：正式清單共六款，既有四款回歸；原免費 CI/CD 設定不變。推送後分開核對遠端 CI、Pages 版本與六款正式站操作。

## 設計

原生 Canvas、固定物理步進、獨立 racer-model.mjs 與 pool-model.mjs。迷你撞球採簡化等質量圓球碰撞、摩擦、球袋與球桌邊界；不宣稱競賽撞球完整規則或精確物理模擬。六顆色球靠近六個球袋，提供容易上手的瞄準練習；不限桿數、無金錢與對戰。

球桌虛線顯示初始方向與第一接觸點；不承諾多次反彈路徑。白球回位避開仍在桌上的球。賽車採車道型碰撞與可預告的波次，不需要連續角度操控。兩款都不新增音訊／存檔或外部服務。

## 本機驗證與覆核

40 項規則測試通過；外框替身 17、既有貪食蛇／翻牌 14、方塊／跳躍 14、新增賽車／撞球 15，共 60 項獨立 Playwright 案例通過。既有遊戲測試只因正式清單增至六款調整預期數量，未放寬玩法驗收。語法、清單、入口與 build 另行驗證。

新遊戲驗證含正常鍵盤完成 1000 公尺（涵蓋全部波型）、碰撞與重玩、減速釋放／觸控取消、六次正常角度／力道擊球清台、進袋、白球犯規安全回位（規則測試）、重複擊球防護、暫停物理與計時、縮放觸控瞄準／取消、旋轉保留狀態、獨立入口。四種尺寸為 1280×900、1024×768、768×1024、800×600；操作控制高度至少 44px 且不超出 iframe。截圖人工檢視完成。

測試途中一項時速恢復判定使用 >80，但前 0.2 秒顯示值四捨五入為 80；改為 >=80 並保留減速時 <60 的對照，未修改遊戲規則。新增兩項觸控取消／旋轉後重新執行該套件全數通過。證據與受驗檔案 SHA256 見 evidence/v0.4.0/。
