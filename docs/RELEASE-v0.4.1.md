# v0.4.1：迷你撞球三角形球陣

日期：2026-11-03；模式：精簡變更；狀態：本機完成，遠端／正式站待驗。

使用者要求「迷你撞球要是三角形球陣開始」。六顆色球改為右側 1／2／3 排等邊三角形，中心距 20.2px（半徑 10px）避免初始重疊；白球在左側 (160,180)，對準球陣頂點。預設方向 0 度、力道 85%，開始後可直接擊球開球。重新開始重建相同球陣、白球、方向與力道；縮圖與玩法說明同步。
