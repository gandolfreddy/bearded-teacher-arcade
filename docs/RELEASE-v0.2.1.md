## 問題與修正

v0.2.0 的遠端 CI 與 deploy 均成功（run 41502786407、提交 2c03165），但上線後獨立 Playwright 首次互動驗收未通過：翻牌遊戲的開始按鈕在模組尚未執行前已顯示可按，點選未產生動作。逐步讀回確認按鈕仍為未初始化狀態，非以遠端綠燈當作完成。

外框現在先隱藏新 iframe，收到該遊戲的 ready 才顯示。兩款獨立 HTML 的開始鈕初始停用，標示正在準備，由 GameHost 初始化後才啟用並回報 ready。停用 JavaScript 時提供提示。上線檢查也先核對 iframe 目標，避免把前一款遊戲的就緒文字誤認成新遊戲已就緒。
